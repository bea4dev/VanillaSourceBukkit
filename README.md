## VanillaSourceBukkit
Multithreaded entity library for Bukkit

### Supported version

```
1.21.1, 1.21.11
```

### Build

Java 21 と Paperweight userdev を使用します。NMS モジュールと出力 JAR は、Paper の
Mojang-mapped runtime に合わせてビルドされます。

```shell
./gradlew build
```

Plugin JAR は `Plugin/build/libs/vanilla_source_plugin-0.0.4.jar` に出力されます。
